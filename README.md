# apple-slides

An agent skill for turning notes and documents into Apple-inspired 16:9 slides, with HTML, PNG, and PDF export.

> 🚧 Work in progress. Not ready for use yet.

## Roadmap

- [ ] Apply a clean, Apple-inspired look
- [ ] Write clear, concise headlines
- [ ] Choose layouts for key messages, data, processes, and comparisons
- [ ] Use relevant images and track their sources
- [ ] Turn documents into slide outlines, with one main idea per slide
- [ ] Check for text overflow, missing images, overlapping elements, and poor contrast
- [ ] Export individual slides as 4K PNGs and generate a deck overview
- [ ] Export slides as a 16:9 PDF
- [ ] Support manual editing in [DeckWerk](https://github.com/vsitzmann/deckwerk)
- [ ] Support Claude Code
- [ ] Support Codex

Not affiliated with Apple Inc.
